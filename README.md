# Portfolio

My personal site — **[dulfazl.github.io/portfolio](https://dulfazl.github.io/portfolio/)**

A hand-built single page: no framework, no build step. CSS custom properties drive the dark theme, the layout is responsive down to mobile, and Open Graph / Twitter card metadata is set up so shared links preview properly.

Open `index.html` in a browser to run it locally.
